### Параметри мережевого підключення

| Параметр | Значення та пояснення |
|---|---|
| Інтерфейс | **Не визначено; перевірити вручну** |
| Тип підключення | **Не визначено; перевірити вручну** |
| MAC-адреса | **Не визначено; перевірити вручну** |
| IPv4-адреса | **Не визначено; перевірити вручну** (мережевий рівень OSI, **3**) |
| Маска підмережі | **Не визначено; перевірити вручну**; префікс **Не визначено; перевірити вручну** (мережевий рівень OSI, **3**) |
| Gateway / шлюз за замовчуванням | **Не визначено; перевірити вручну** (мережевий рівень OSI, **3**) |
| Broadcast (IPv4) | **Не визначено; перевірити вручну** (мережевий рівень OSI, **3**) |
| Мережа | **Не визначено; перевірити вручну** |
| Hosts / доступні адреси вузлів | **Не визначено; перевірити вручну** |

**Пояснення:** IP-адреса та маска підмережі використовуються на **мережевому рівні OSI (3)** і визначають адресу вузла та межі підмережі. MAC-адреса працює на **канальному рівні OSI (2)**. Шлюз за замовчуванням передає пакети до мереж поза локальною підмережею. IPv4 broadcast — спеціальна адреса для широкомовної доставки пакетів у межах підмережі. Під **hosts** мається на увазі кількість адрес, доступних для вузлів, без адреси мережі та broadcast (для типових підмереж /30 і ширших).
