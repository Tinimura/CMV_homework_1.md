# Домашнє завдання № 1-Основи комп’ютерних мереж

Практична робота до першого змістового модуля з комп’ютерних мереж. Мета-дослідити параметри мережевого інтерфейсу Linux, таблицю маршрутизації та відмінність між локальною і публічною IP-адресами.

## Завдання

1. **Дослідження мережі (`ip a`).** Визначити мережевий інтерфейс, тип підключення, MAC-адресу, IPv4-адресу, маску підмережі, шлюз, broadcast та кількість адрес для вузлів. Пояснити відповідні рівні моделі OSI.
2. **Дослідження маршрутизації (`ip r`).** Переглянути маршрути та проаналізувати походження маршруту (`proto`). Важливо: `proto` в таблиці маршрутизації не завжди показує, як отримано саму IP-адресу.
3. **Публічна IP-адреса (`curl ifconfig.io`).** Визначити адресу, видиму зовнішньому сервісу, порівняти її з локальною адресою та пояснити роль маршрутизатора і NAT.

## Структура репозиторію

```text

└── homework/
    └── module1/
        └── lastname_homework_1.md
```

`lastname_homework_1.md`-шаблон. Для здачі потрібно сформувати файл зі своїм прізвищем і **реальними результатами команд**.

## Як виконати

Потрібні Linux, Python 3, утиліти `ip` (пакет `iproute2`) і `curl`, а також доступ до Інтернету для третього завдання.

### 1. Перевірити команди в терміналі Linux

```bash
ip a
ip r
curl ifconfig.io
```

### 2. Сформувати Markdown-звіт

Із кореня репозиторію виконати:

```bash
python3 generate_homework.py --surname ivanenko --student "Іваненко Іван Іванович"
```

Замінити `ivanenko` та ПІБ на власні дані. Скрипт збере інформацію з **того Linux-середовища, де його запущено**, і збереже файл:

```text
homework/module1/ivanenko_homework_1.md
```

> Якщо скрипт виконати у контейнері або віртуальній машині, результати можуть описувати мережу контейнера або віртуальної машини, а не основного комп’ютера.

### 3. Перевірити результат

Відкрити створений `.md`-файл і перевірити, що:

- указано власне ПІБ;
- наведено справжній вивід `ip a`, `ip r`, `curl ifconfig.io`;
- правильно визначено основний інтерфейс і тип підключення;
- усі поля заповнені, немає позначок «Не визначено; перевірити вручну» або незаповнених шаблонів;
- порівняно локальну й публічну IPv4-адреси та наведено пояснення українською мовою.

Якщо `curl ifconfig.io` поверне IPv6, для коректного порівняння з локальною IPv4-адресою можна додатково виконати `curl -4 ifconfig.io` та пояснити це у звіті.

## Як здати

1. Завантажити готовий файл `homework/module1/прізвище_homework_1.md` до GitHub-репозиторію, зберігаючи структуру папок.
2. Надати викладачу посилання **саме на файл** у GitHub.
3. Додатково прикріпити цей `.md`-файл на навчальній платформі.

**Важливо:** не здавати шаблон замість звіту. Результати мережевих команд залежать від конкретного пристрою та підключення.
