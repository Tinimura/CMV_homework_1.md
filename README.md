# Домашнє завдання № 1 — Основи комп'ютерних мереж

**Студент:** Черкасов Михайло Вячеславович  
**Навчальний модуль:** Основи комп'ютерних мереж

У цьому репозиторії наведено практичний звіт з дослідження мережі Ubuntu у WSL на комп'ютері `ASUSTUF-MISHA`.

## Виконані завдання

1. **Дослідження мережі:** результат `ip a`, інтерфейс, MAC, приватна IPv4-адреса, маска, шлюз, broadcast, hosts та рівні OSI.
2. **Дослідження маршрутизації:** результат `ip r`, аналіз маршрутів та позначення `proto kernel`.
3. **Публічна IP-адреса:** результат `curl ifconfig.io`, діагностика помилки та порівняння з публічною адресою `85.238.97.100`, отриманою альтернативним способом через Windows.

## Звіт

**[Відкрити виконане домашнє завдання](homework/module1/cherkasov_homework_1.md)**

Основні команди, використані в Ubuntu:

```bash
ip a
ip r
curl ifconfig.io
```

Виконувались також діагностичні команди `ping`, `getent` та `curl -v` для перевірки мережевої доступності. Публічна IP-адреса була отримана через Windows, оскільки TCP-з'єднання з сервісами визначення IP у WSL завершувалися тайм-аутом.
